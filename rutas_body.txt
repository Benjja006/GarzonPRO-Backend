======================================================
MICROSERVICIO: AUTH-SERVICE
======================================================

======================================================
1. REGISTRAR USUARIO
======================================================
MÉTODO: POST
RUTA MC: http://localhost:8081/auth/register
RUTA API: http://localhost:8080/auth/register
BODY:
{
  "username": "usuario_prueba",
  "pin": "1234",
  "nombre": "Juan",
  "apellido": "Pérez",
  "correo": "juan@email.com",
  "rol": "GARZON/ADMIN/COCINERO"
}

======================================================
2. INICIAR SESIÓN (LOGIN)
======================================================
MÉTODO: POST
RUTA MC: http://localhost:8081/auth/login
RUTA API: http://localhost:8080/auth/login
BODY:
{
  "username": "usuario_prueba",
  "pin": "1234"
}

======================================================
3. ACTUALIZAR DATOS DE USUARIO
======================================================
MÉTODO: PUT
RUTA MC: http://localhost:8081/auth/usuarios/actualizar/{id}
RUTA API: http://localhost:8080/auth/usuarios/actualizar/{id}
BODY:
{
  "username": "usuario_admin",
  "pin": "4321",
  "nombre": "Juan",
  "apellido": "Pérez",
  "correo": "juan_nuevo@email.com",
  "rol": "Administrador"
}

======================================================
4. ELIMINAR USUARIO
======================================================
MÉTODO: DELETE
RUTA MC: http://localhost:8081/auth/usuarios/eliminar/{id}
RUTA API: http://localhost:8080/auth/usuarios/eliminar/{id}
BODY: (Vacío)

======================================================
5. CREAR PLATO
======================================================
