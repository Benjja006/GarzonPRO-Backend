# 🍽️ GarzonPRO - Backend

Proyecto backend desarrollado en **Java** con **Spring Boot** para la lógica de negocio de gestión de restaurantes y servicios gastronómicos.

---

## 📌 ¿De qué trata el proyecto?

**GarzonPRO-Backend** es el núcleo de software orientado a modelar y organizar los procesos clave de atención en un establecimiento:

- **Módulo de Pedidos:** Gestión de comandas e ítems solicitados por las mesas.
- **Módulo de Mesas:** Control de disponibilidad y asignación de mesas en el salón.
- **Módulo de Productos:** Estructuración de la carta, precios y categorías del menú.
- **Gestión de Personal:** Modelado de roles para garzones, cocineros y administradores.

---

## 🛠️ Tecnologías

- **Lenguaje:** Java
- **Framework:** Spring Boot
- **Gestor de Construcción:** Maven
